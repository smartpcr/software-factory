# Graph Memory Schema

Code knowledge graph schema and interfaces for the agent memory system.  
**Schema version: 0.3.0** — targeting **Neo4j** as persistence backend.

## Structure

```
src/
  GraphMemory/              # .NET 8.0 class library
    Models/
      Enums.cs              # NodeKind, EdgeKind, Layer, etc.
      SupportingTypes.cs    # Provenance, VersionRange, CallSite, ExpertiseEvidence, etc.
      GraphNode.cs          # Node container (id, kind, properties, ...)
      GraphEdge.cs          # Edge container (id, kind, source, target, ...)
      CodeGraph.cs          # Root graph object
      NodeProperties.cs     # Typed property bags per node kind
      EdgeProperties.cs     # Typed property bags per edge kind
    Interfaces/
      IGraphStore.cs        # CRUD + traversal + diff + vector search + snapshot interface
      IGraphValidator.cs    # Validation interface + result types
    Validation/
      GraphValidator.cs     # Validates graph invariants
    Serialization/
      GraphJsonOptions.cs   # Shared JsonSerializerOptions
      GraphConverters.cs    # Kind-discriminated JSON converters
      PropertyConverters.cs # INodeProperties/IEdgeProperties converters
      SnakeCaseEnumConverters.cs  # Enum <-> snake_case wire format
      EnumLookup.cs         # Fast string-to-enum parsing
    TypeScript/
      graph-memory.d.ts     # TypeScript interface definitions (cross-language contract)
  GraphMemory.Tests/        # xUnit test project
    FixtureBuilder.cs       # Builds >=50-node realistic test graph
    SchemaParityTests.cs    # Schema validation, parity, round-trip tests
json-schema/
  graph-memory.schema.json  # Canonical JSON Schema (generated by gen_schema.py)
gen_schema.py               # JSON Schema generator (single source of truth)
```

## Cross-Language Contracts

This workstream publishes **three canonical contract artifacts**:

1. **C# interfaces and models** (`src/GraphMemory/`) — the canonical .NET implementation
2. **TypeScript interfaces** (`src/GraphMemory/TypeScript/graph-memory.d.ts`) — discriminated union types for downstream TS consumers (kind narrows properties)
3. **JSON Schema** (`json-schema/graph-memory.schema.json`) — language-agnostic validation schema

All three are kept in sync: C# models are the source of truth, the TypeScript `.d.ts` mirrors them with discriminated unions, and `gen_schema.py` generates the JSON Schema from the same structure.

## Common Node/Edge Fields

Every node carries: `id`, `kind`, `name`, `properties`, plus optional fields:
`qualifiedName`, `repoId`, `provenance`, `version`, `layer`, `createdAt`,
`updatedAt`, `versionRange`, `snapshotId`, `stale`, `contentHash`, `embedding`,
`extensions`.

Every edge carries: `id`, `kind`, `source`, `target`, `properties`, plus optional:
`provenance`, `version`, `layer`, `createdAt`, `updatedAt`, `versionRange`,
`snapshotId`, `stale`, `sourceRepoId`, `targetRepoId`, `extensions`.

## Layers

| Layer | Description |
|-------|-------------|
| `structural` | File-system and AST containment hierarchy |
| `call_chain` | Function/method call relationships |
| `semantic` | Embedding-based similarity and clustering |
| `expertise` | Human and agent-derived knowledge |

## IGraphStore Interface

```csharp
public interface IGraphStore
{
    // Node CRUD
    Task AddNodeAsync(GraphNode node, CancellationToken ct = default);
    Task<GraphNode?> GetNodeAsync(string id, CancellationToken ct = default);
    Task UpdateNodeAsync(GraphNode node, CancellationToken ct = default);
    Task RemoveNodeAsync(string id, CancellationToken ct = default);
    Task<IReadOnlyList<GraphNode>> GetNodesByKindAsync(NodeKind kind, CancellationToken ct = default);
    Task<IReadOnlyList<GraphNode>> FindByNameAsync(string name, NodeKind? kind = null, CancellationToken ct = default);
    Task<GraphNode?> GetNodeAtCommitAsync(string id, string commitSha, CancellationToken ct = default);

    // Edge CRUD
    Task AddEdgeAsync(GraphEdge edge, CancellationToken ct = default);
    Task<GraphEdge?> GetEdgeAsync(string id, CancellationToken ct = default);
    Task UpdateEdgeAsync(GraphEdge edge, CancellationToken ct = default);
    Task RemoveEdgeAsync(string id, CancellationToken ct = default);

    // Traversal
    Task<IReadOnlyList<GraphEdge>> GetOutgoingEdgesAsync(string nodeId, EdgeKind? kind = null, CancellationToken ct = default);
    Task<IReadOnlyList<GraphEdge>> GetIncomingEdgesAsync(string nodeId, EdgeKind? kind = null, CancellationToken ct = default);
    Task<IReadOnlyList<GraphNode>> GetNeighboursAsync(string nodeId, EdgeKind? edgeKind = null, CancellationToken ct = default);
    Task<IReadOnlyList<TraversalPath>> TraverseAsync(TraversalOptions options, CancellationToken ct = default);

    // Vector search
    Task<IReadOnlyList<VectorSearchResult>> VectorSearchAsync(VectorSearchOptions options, CancellationToken ct = default);

    // Batch diff
    Task<DiffResult> ApplyDiffAsync(GraphDiff diff, CancellationToken ct = default);

    // Snapshots
    Task<GraphSnapshot> SnapshotAsync(string? description = null, CancellationToken ct = default);
    Task RestoreSnapshotAsync(string snapshotId, CancellationToken ct = default);
    Task<IReadOnlyList<GraphSnapshot>> ListSnapshotsAsync(CancellationToken ct = default);

    // Bulk
    Task<CodeGraph> ExportAsync(CancellationToken ct = default);
    Task ImportAsync(CodeGraph graph, CancellationToken ct = default);
    Task ClearAsync(CancellationToken ct = default);
}
```

See [neo4j-mapping.md](neo4j-mapping.md) for the canonical mapping between

implementations targeting Neo4j **must** follow this mapping.

## Extension Keys

All `extensions` dictionaries use restricted keys: every key must start with
`x-` (e.g. `x-myTool`, `x-neo4j`). This is enforced by JSON Schema
(`propertyNames.pattern: "^x-"`), the C# `GraphValidator`, and documented
in the TypeScript interfaces.
