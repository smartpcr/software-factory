# Chat setup illustrations

`slack-basic-information.png` and `slack-bot-token.png` are unmodified example
screenshots from [Slack's app setup tutorial](https://docs.slack.dev/tools/bolt-python/creating-an-app/),
retrieved 2026-09-11. They are credited and linked in the setup guide. Slack's
example bot token is already blurred in the source image.

Original image URLs:

- https://docs.slack.dev/assets/images/basic-information-page-e7d531fe4721830376d61a91de5d933e.png
- https://docs.slack.dev/assets/images/bot-token-3d6c761238c7a66557fd08d00a2a1b0c.png

`telegram-token-map.svg` is an original Forge illustration with example values.
It is not a screenshot of a real account and contains no credential.
