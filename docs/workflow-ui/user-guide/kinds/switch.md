# Switch Node

## Description

Multi-way branching node. Evaluates an expression and routes to the matching case branch.

## Properties

See the property grid in the designer for configurable fields when this node kind is selected.

## Connections

- **Input**: Receives messages from upstream nodes
- **Output**: Sends completion/failure messages to downstream nodes

## Example Usage

1. Drag the **Switch** node from the palette onto the canvas
2. Connect it to upstream and downstream nodes
3. Configure its properties in the property grid
